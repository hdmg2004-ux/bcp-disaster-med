# 病院医療継続 活動ツール（β v11.0）

病院の災害対策本部が、発災時に「いま何を判断し、何を指示するか」を確認しながら動くための、無償の単一HTMLツールです。

- 発行元：東京医療減災Labo（https://gensai-labo.tokyo/）
- 開発：東京医療減災Labo／東京都立広尾病院
- 費用：無償

## 使い方

1. [Releases](https://github.com/hdmg2004-ux/bcp-disaster-med/releases/latest) から `bcp_disaster_med.html` をダウンロードします。
2. ダウンロードしたファイルをダブルクリックして、ブラウザで開きます。
3. 平時のうちに、病院の施設設定を入力しておきます。

インターネットに接続できない場面でも、ダウンロードしたファイルのまま使えます。入力した内容は、お使いの端末のブラウザに保存され、外部には送信されません。

## 引き継ぎ

新しい版に替えるとき、別のパソコンへ移すときは、ツール内の「バックアップ」で書き出して、移した先で読み込みます。
